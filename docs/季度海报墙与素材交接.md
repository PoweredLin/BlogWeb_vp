# 季度海报墙与页面素材交接

## 本轮入口

- 公开博客 `/anime`：独立季度海报墙，默认当前季度，切换往季；无公开内容时显示空状态。
- 私人空间 `/admin/anime-wall`：所有番剧收藏的季度、播出说明、公开开关；每张卡片独立保存。
- 兴趣收藏 `/admin/life/library`：同一份 library 数据，采集确认保存后自动出现，不额外复制数据。
- 管理 `/admin/management`：页面、片头、公开番剧、审核、站点设置和访问凭证。
- 功能 `/admin/features`：自动化、邮件、文档、开发书架、JSON 导入及空间外观。
- 页面与片头 `/admin/page-layout`：启用片头、播放频率、强调色、模块顺序，以及手动精选画报。

## 如何使用

1. 功能 → 自动化，运行季度新番，预览并确认保存到收藏。
2. 管理 → 季度海报墙，核对 `2026-Q4` 这样的季度，按需开启公开并保存。
3. 打开公开博客的“季度番剧”，核对相应季度。
4. 管理 → 页面与片头 → 手动精选，选择番剧或首页素材，也可上传 PNG/JPEG/WebP。
5. 已选画报支持预览、上移、下移、移除，最多 18 张；保存后对访客生效。
6. 开屏文字使用博客设置中的网站标题。会话/设备播放策略可能让片头不再自动播放，验收时使用新浏览器会话或设为每次播放。

旧收藏缺少季度时显示在“待整理”；不会根据当前日期猜测历史季度。新采集使用来源季度，包括自动季度模式。所有采集默认私有，不会自动公开。

## 数据接口与安全边界

| 接口 | 用途 |
| --- | --- |
| `GET /api/public/anime?season=2026-Q4` | 只读公开海报，返回 items 和全部可用 seasons；不传 season 返回全部公开番剧 |
| `GET /api/private/state` | 站主读取原有私人收藏 |
| `PUT /api/private/records/library/{id}` | 保存完整收藏及 version；并发冲突返回 409 |
| `GET /api/page-layout` | 公开页面布局及精选片头素材 |
| `GET/PUT /api/private/page-layout` | 站主配置片头和模块；写入携带 version |
| `POST /api/studio/upload` | 站主上传，返回 `{url}`；前端 upload helper 包装为 `result.url` |

收藏增加 `season`（空或 YYYY-Q1…Q4）、`broadcast`（最多100字符）、`public`（默认 false）。无需重建数据库或手动 SQL 迁移；旧记录可继续读取。

公开接口只返回 owner 的显式公开番剧：id、标题、季度、播出文字、封面、制作方和标签。不返回私人感想、评分、进度。公开番剧封面允许匿名读取，取消公开后若没有其他公开文章/精选片头引用则恢复私有。把私人图片加入精选片头本身也是公开授权。

## SQLite 是否够用

当前 2 核 4G、单实例、个人创作和以浏览为主的流量，SQLite 足够。现有连接启用 WAL、busy_timeout=5000 和事务，适合少量写入；海报读取不会触发重新抓取。

保持单实例和有限后台任务并发。定期用项目备份命令获取一致数据库快照，并一起备份 uploads、配置与密钥；不要在运行时只复制 sqlite 主文件而漏掉 WAL。完整数据文件名和备份流程以部署文档为准。

只有需要多台服务器共同写库、持续出现 SQLITE_BUSY、或自动化/多人写入明显增加时才考虑 PostgreSQL。换数据库不能代替抓取限流、图片缩略化和后台队列。现阶段更应关注图片体积、定时备份与监测写锁。

## Claude 设计提示词

请基于现有 Vue3 组件优化“拾帧之间”的季度放映室和私人空间。公开海报墙用编辑感排版、克制的电影编号与海报动效，默认本季度；私人空间保留简约工作室和浓厚私宅两套视觉性格。管理用于站点公开配置与审核，功能工具箱用于日常工作，不重新混成后台。片头编辑器应明显展示精选素材、上传状态、顺序和公开提示。

可以调整布局、CSS、视觉组件、响应式和动效，保留 API、路由、权限、version 并发控制与数据字段。不要把私人收藏全部公开；不要在前端直接抓取第三方图片。每个页面应覆盖 loading/error/empty，兼容键盘及 prefers-reduced-motion。素材与入口按上表查找，不能只修改构建产物。不得把所有角色插画替换成同一张图。公开海报只能使用 `/api/public/anime` 返回的数据；片头只有站主保存后的精选素材才公开。

## 本地与升级

运行 `node scripts/build.mjs`，然后 `node scripts/python.mjs -m backend.demo --port 4322`。demo 保留已有数据及账号，不重复初始化密码。

生产仍按 `V10-upgrade-and-rollback.md` 停写备份、预演、构建、验收后切换。本轮不操作线上、不推送仓库、不重置账号。

验证：`node scripts/python.mjs -m pytest tests/test_backend.py -q` 31 项通过。`node tests/anime-wall.mjs` 使用独立临时数据库，验证公开墙、手机布局、管理/功能入口、收藏封面读取及失效兜底、片头上传预览/保存/重载/移除。构建入口为 `node scripts/build.mjs`。浏览器移动端截图在 `test-results/anime-wall-mobile.png`，测试不改已有 demo 数据。
