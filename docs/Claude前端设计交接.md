# Claude 前端设计交接

先阅读 [API 基础与前端交接](API-frontend-foundation.md)。本轮新增首页聚合、文章/番剧/素材分页和自动化摘要接口，后续新页面优先接入这些接口，避免加载完整私人空间。管理员可在 `/admin/api-reference` 下载 OpenAPI 与记录字段契约；共享类型辅助位于 `source/shared/frontend-api.ts`。视觉改版不应改变公开范围、审核或保存冲突规则。

本说明用于把品牌首页和个人空间视觉交给 Claude 做设计迭代。站名定为“拾帧之间”；仓库名和域名保持不变。目标是重做表现层，不重写现有业务。首页文字从站点设置读取，其他页面沿用统一品牌名，不使用 Linbook，也不要擅自提出替代名称。

## 项目上下文

- 这是已经运行的个人网站升级项目，Vue 3 前端、FastAPI 后端，当前部署形态是 Docker + SQLite。
- 公开博客、个人空间和管理设置属于同一产品，但权限不同。访客只能看到公开内容；个人空间与管理页面只对站主开放；读者只能编辑自己的资料。
- “私宅”是“死宅”的谐音：它应当明显呈现对番剧、游戏、Galgame、角色、路线、收藏和进度存档的喜好，而不只是普通仪表盘换一张壁纸。
- 目前个人空间中已有简约工作室/私宅两种主题、收藏库、角色互动、文章草稿、说说、相册、日常工具和 Git 动态。请先阅读对应现有页面，不要重复造导航或第三套 Studio。
- 个人空间用于创作、兴趣和日常；管理负责公开配置、审核和访问权限；功能工具箱负责自动化、邮件、文档和开发书架。管理与功能使用同一空间外壳，但有独立入口和子导航，不再把所有工具混在管理概览里。

## 设计范围与代码边界

优先处理：

1. 公开首页的电影式图片拼字开场，并衔接现有轮播首页。
2. 私宅主题的个性化表达、信息层次和空间布局。
3. 简约工作室与私宅之间更明确的视觉差异。
4. 个人空间模块的显示/排序/背景/主题设置入口与预览表现。
5. 桌面和窄屏下的导航、内容密度、动画、空状态与错误状态。

原则上只改 `source/admin/src/integration/` 下视觉组件及必要的样式/静态资源；博客首页代码位置需先从 `vite.source.config.mjs` 与 `source/` 路由中确认，再把目标文件清单写在开始说明里。新增组件沿用现有 API service，不要在视觉组件里直接拼接未经约定的业务请求。

未经单独确认不要修改：

- FastAPI 路由、数据库结构/迁移、权限判定和认证流程。
- API 字段、请求方法、URL、角色能力、评论审核规则。
- Docker、部署端口、`.env`、Token、SMTP 凭据或线上数据。
- “拾帧之间”站名、仓库名、公开文章 URL 和导航语义。
- 与视觉目标无关的第三方依赖。优先使用仓库现有 Vue、Element Plus、图标和动画能力。

若确实需要新视觉设置字段，先提交字段提案，说明默认值、兼容旧配置、校验和恢复默认行为；不允许前端静默发明只在浏览器生效的“保存设置”。

## 首页电影式开场提示词

当前工作区已有可运行的拼字片头原型：站点设置选择“拼贴手记”后，使用最多 8 张公开文章封面/首页照片在短动画中拼出站点标题，可跳过，之后显示原有轮播首屏。代码在 `source/blog/src/integration/LinFrameIntro.vue` 与 `LinHero.vue`。Claude 的任务是改善镜头语言、构图、图块质感和转场细节；先实际运行并检查现有行为，不要把已完成的功能改回静态稿或另造一套片头。现有组件契约为 `title`、`photos` 输入和 `done` 事件，站点配置字段 `heroMode` 控制开关。

```text
请在现有 Vue 3 站点首页优化电影式图片拼字开场。站名从站点配置读取，仓库名和域名不变。工作区已经有可运行原型，先阅读并保留现有 `LinFrameIntro.vue` 组件输入 `title`/`photos`、`done` 事件，以及 `heroMode` 配置和跳过逻辑；本次主要改善视觉表现，不要复制一套业务实现。

视觉目标：若干张来自本站相册、公开文章封面或站主挑选素材的照片组成图块/胶片帧，最终拼出“拾帧之间”。镜头短暂停留，再通过一次克制但有电影感的推进、遮罩或景深转场进入目前已经存在的轮播首页。开场是首页内容的一部分，不是独立营销落地页；转场之后原有轮播首页的内容与导航仍然完整。

交互要求：提供明显但不抢画面的“跳过”入口；首次访问默认播放，之后遵从用户选择（重播/跳过）；允许通过 URL 深链直接进入文章而不播放；播放完成后正确清理动画和事件监听。支持 prefers-reduced-motion，低动效时用短淡入或直接显示首页。图片未加载、脚本失败、站名为空或弱网超时，都必须直接显示现有首页，不能留空屏或卡在 loading。

性能要求：优先 CSS transform/opacity 和少量 DOM；不要引入 Three.js、长时间 Canvas、自动播放视频或庞大动画依赖。只请求有限数量的小尺寸缩略图；首屏关键字/首图优先，其余延迟加载；动画期间不要同时下载整站相册。切换后释放临时资源。桌面和手机都不得横向溢出，文字和按钮不能重叠。

实现前先查看当前首页组件、数据接口和站点设置字段，给出目标文件清单。保留路由、API 和已有 carousel 数据契约。完成后提供桌面宽屏、桌面窄屏和手机截图，验证跳过、首次/再次访问、减少动效、图片失败、直接深链和控制台无错误。不要修改后端。
```

## 私宅与个人空间提示词

```text
请重做现有个人空间的视觉层，重点让“私宅”主题更像个人 ACG 收藏与生活存档据点，而不是普通 SaaS 仪表盘。品牌为“拾帧之间”。它和“简约工作室”必须一眼可区分，但两者共用已有业务数据和权限。请先阅读 LinSpaceLayout.vue、LinRoom.vue、LinLife.vue、LinAppearance.vue、space.scss、space-v8.scss、workbench.scss，以及路由表；开始前列出拟改文件和保留的 API/props/events。

私宅视觉方向：像有主人长期生活的私人房间/收藏空间，呈现我正在追的番、游戏/Galgame、推送中的新番、角色偏好、路线和进度、收藏封面墙、最近写下的感想、草稿续写入口、Git 活动和生活支线。用封面色彩、标签、进度轨迹、季节/章节等真实数据建立氛围；避免全页堆卡片、重复的大数字、虚构统计或随机装饰图。角色和背景图由现有配置驱动，空数据时也要像可使用的空间，不显示假的内容。

简约工作室方向：高信息密度、低装饰，适合写文章、看草稿、处理评论/注册和配置。保留清楚的内容列表、筛选、状态和快捷操作。两个主题切换时不仅换颜色，还要调整页面结构、导航权重、封面展示比例、标题层级和动画节奏，但不可改变同一按钮的业务语义。

可编辑性只覆盖已登记的页面模块：模块显示/隐藏、顺序、少量布局预设、壁纸/背景、透明度、主题与动效偏好。提供即时预览、保存成功/失败提示、恢复默认和窄屏布局；未保存修改要能辨认。不要做任意组件拖拽画布、任意 CSS/脚本输入或企业低代码搭建器。设置入口放在个人空间现有“管理/空间外观”中，避免复制出第二个中台。

保持现有路由、字段、API、鉴权和事件契约。数据通过现有 service/composable 加载，展示组件只负责展示与发出事件。认真处理 loading、空、错误、权限不足、超长标题、图片损坏、窄屏、键盘焦点和 prefers-reduced-motion。页面不要展示教程式说明或功能宣传文案。

完成时给出文件清单、哪些 API/字段未动、桌面 1440x900 与手机 390x844 截图，并实际检查主题切换、外观保存/恢复、文章草稿入口、收藏进度和评论管理入口。报告无法完成的状态，不要用静态假页面掩盖。
```

## 组件与数据边界

在动手前以代码核对以下组件/页面的真实职责，不要假设文件仍与此表一致：

| 区域 | 主要现有入口 | 数据/权限边界 |
| --- | --- | --- |
| 空间外壳、主题、导航 | `LinSpaceLayout.vue` | 主题偏好来自站主资料；路由由现有 router 控制 |
| 私宅首页 | `LinRoom.vue` | 私人收藏、草稿和生活数据，不得公开输出 |
| 外观设置 | `LinAppearance.vue` | 背景、透明度、动效、模块配置需通过现有/新增明确 API 保存 |
| 兴趣与生活 | `LinLife.vue` | 仅站主可访问；沿用已有记录 CRUD |
| 管理入口 | `LinManagement.vue`、`router/index.ts` | 站主专属管理页面；服务端仍是权限最终判定者 |
| AI 接入、邮件 | `LinAccessTokens.vue`、`LinMailSettings.vue` | 只优化信息展示；密钥创建后只显示一次，SMTP 密码永不回显 |
| 博客首页 | 以当前 Vite 入口及路由实际定位 | 只使用公开首页数据；拼字图片不能引用私人上传文件 |

若现有模块排序/可见性还没有后端字段，先把编辑控件与字段契约作为单独提案，不要把设置保存到 localStorage 后宣称已完成跨设备保存。

## 验收和交付

- 站名使用当前设置值，开场拼字、跳过、完成转场和首页轮播衔接均可演示。
- 低动效、无图片、慢请求、关闭动画、直接深链时正常到达目标内容。
- 私宅与简约工作室不仅换色，还体现不同的空间结构和内容重点。
- 现有 API 请求/响应、路由、权限、文章/收藏数据均未改变；若需变更先列提案。
- 1440x900、1024x768、390x844 检查无重叠、横向滚动和文字溢出。
- 产出变更文件清单、截图、验证步骤、已知问题和未完成项；不部署、不推送、不连接线上数据库。
