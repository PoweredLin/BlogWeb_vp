# 让视觉可以继续更新：主题、字体与接口约定

网站的风格可以反复迭代，创作流程和权限不能随视觉重做而失效。林间笔记将公开博客、私人空间和管理功能放在不同入口，通过已有接口连接。前端接手时先明确数据来源，再修改排版、配色、层次与动效。

## 小范围调整也尊重主题

首页滚动文字条原先直接使用深绿底，与两套博客主题的纸面背景反差过大。本次改为从主题纸色、墨色混合得到淡色背景，文字沿用主题辅助色。这样明暗模式与画廊主题仍能各自表达，不需要为每个页面硬编码一种颜色。

Lin 标识和浏览器图标统一，侧栏使用同一个 `/favicon.svg`，减少旧头像残留。关于页以网站本身的故事和使用方式为主，开源起源与许可证折叠保留；重构并不抹除曾经使用的开源贡献。

## 字体不依赖外部运行服务

本次使用 Inter 的可变字重拉丁字体处理界面数字与英文，用 Lora 处理 Lin 标识、英文装饰与部分标题。中文正文继续回退到系统中文字体，避免为少量装饰下载庞大的完整中文字库。

字体文件保存在 `public/fonts/`，约 84 KiB；`public/fonts.css` 定义字重范围与 `font-display:swap`。`manifest.json` 保留下载地址、文件大小和 SHA-256，OFL 许可随资源提交。维护脚本 `scripts/fetch-fonts.py` 固定 Fontsource 版本，不在用户访问页面时执行。

保留旧 iconfont：它是图标资源，不是待替换的正文文字字体。直接删除会令旧组件的图标变成空框。网络中断或字体缺失时，系统回退字体保证内容仍可阅读。

## 从接口契约接手页面

管理员通过 `/admin/api-reference` 下载契约。新页面优先使用分页与聚合接口，并处理加载、空数据、失败重试、未登录和保存冲突。不要为了布局方便加载整个私人空间或将 Token 写入浏览器构建结果。

建站时间属于公开站点设置，服务状态属于实时读取。前者由用户填写含时区的时间戳，后者来自 `/api/public/status`。两者不能混用：进程重启不应清零建站时间，网站运行天数也不是无故障运行时长证明。

构建入口为 `node scripts/build.mjs`，不要直接改 `public/blog-app` 的生成物。文章、说说、相册及运行状态都使用真实数据，后续 Claude 设计可以替换表现层，不需要另建一套业务后台。
