# V9 安全与验证记录

## 权限与部署边界

只有站主管理员可以发布、修改文章和说说、管理相册、访问个人空间及生活记录。注册审核通过的是读者账号，不能通过直接调用 API 获得创作权限。评论提交后统一进入待审核，包括站主自己的评论。公开图片必须被公开内容引用，否则只允许上传者或站主访问。

生产环境禁用网页初始化与 API 文档；使用离线命令创建或重置站主。没有内置默认密码。旧 V8 密码哈希保持兼容；新密码至少 10 字符。会话使用随机令牌，数据库只存哈希，Cookie 使用 HttpOnly、SameSite=Strict，生产强制 Secure。改密码撤销旧会话。

写入请求校验精确 Origin，自动化导入使用独立令牌和幂等键。SQLite 使用参数化查询、事务与版本冲突检查。Markdown 禁止原始 HTML，页面设置 CSP；静态服务采用白名单，不开放整个项目目录。

注册验证码绑定来源、有效期与一次性使用；登录、注册、评论有持久频率限制。验证码只提供基础反自动化能力，不保证能抵抗 OCR。Nginx 必须覆盖 X-Forwarded-For，后端只信任指定代理地址，详见部署文档。

请求体限制 12MiB、读取期限 30 秒；单图限制 8MiB、2400 万像素，实际解码校验格式。容器使用 UID10001、只读根文件系统、移除 capabilities、禁止提权，只开放回环端口。运行限制 768MiB / 1.5 CPU；不是无限并发服务，大流量应由 Nginx 限流保护。

Git 动态只访问固定的 GitHub/Gitee API，不跟随重定向。响应最大 2MiB、总超时 6 秒。缓存写入 SQLite，后台刷新有互斥租约；正常 30 分钟、异常 15 分钟、限流至少 1 小时冷却。GitHub token 仅留在服务端且不会发送给 Gitee。

## 性能测量与限制

本地 Windows、200 篇文章、每个接口 80 次请求、8 并发：单篇 API P95 约 23ms，公开列表约 200ms，首页约 105ms。该结果不是服务器上的 SLA；共享电脑负载和网络会改变实际延迟。公开列表保留旧版全文搜索字段，200 篇测试响应解压后约 936KB，后续文章量很大时应改后端分页搜索。

Docker Desktop 上，测试容器重启后空闲内存约 45.7MiB，CPU 快照约 0.14%；镜像约 186MiB。这只是空闲快照，不能代表上传图片、渲染文章或并发访问时的峰值。Uvicorn 使用单进程、32 并发上限；超限会返回 503，不会无限创建任务。容器系统包未做独立漏洞扫描，依赖审计覆盖 npm/Python 包。

本次是自动化安全回归与代码检查，不是第三方渗透测试，也不能保证不存在未知漏洞。没有对线上网站进行攻击测试。上线前按部署文档在隔离端口验证真实备份，再切换反向代理；保留旧版本与同一时间点的完整数据备份。
