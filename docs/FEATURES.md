# V9 功能与权限

## 三个入口

| 入口 | 使用者 | 内容 |
|---|---|---|
| `/` | 所有人 | 博客首页、文章、归档、分类标签、说说、相册、关于、RSS |
| `/admin/room` | 站主 | 私人空间：日常、兴趣收藏、角色互动、Git 动态、创作入口 |
| `/admin/management` | 站主 | 文章、说说、相册、分类标签、评论审核、注册审核、读者、博客设置 |
| `/admin/account` | 已批准的读者 | 自己的头像、简介、资料；无创作或空间管理权限 |

工作台和管理使用同一个 Vue 外壳。私宅与简约是两套空间外观，不是两个后台。公开博客有纸感/画廊外观与横排/网格列表，读者不会看到站主的私人记录。

## 创作

- 文章支持 Markdown、目录、预览、封面、分类标签、摘要、置顶、原创/转载类型、原文链接、排序。
- 草稿、私密文章不公开；预约文章在 `publishAt` 到达后公开。
- 修改和删除携带版本号。另一个标签页已经修改时返回冲突，不静默覆盖。
- 新建记录的 `clientId` 防止网络重试生成重复内容。
- 说说独立于文章，适合短文和分享；相册包含标题、图片、说明。两者都支持公开/私密/草稿。
- 分类标签可创建、重命名；重命名同步文章，仍在使用的条目不能直接删除。

## 评论与注册

- 所有评论一律进入待审核，包括站主自己的测试评论；批准后才在公开页面出现。
- 可在博客设置关闭新评论。留言有长度限制、频率限制和隐藏反垃圾字段。
- 注册需填写账号、昵称、10 字符以上密码、申请说明、服务端图片验证码。验证码 3 分钟有效、绑定来源 IP、使用后失效。
- 注册申请由站主批准后才能登录。批准后身份为读者，不能写文章或访问私人数据。
- 站主可停用读者、重置读者密码；这些操作会撤销该读者的已有会话。

## 私人空间

- 任务：列表/看板、优先级、项目、到期日、完成状态、搜索。
- 日历：按日/月查看任务与记录。
- 习惯：计数、数值、是/否打卡，历史打卡只读。
- 专注：25/45/60 分钟，暂停、继续、取消，结束后记入专注记录。
- 健康：步数、消耗、摄入、饮水、体重、运动、心情与餐食。
- 睡眠：起止时间、深睡/浅睡/REM/清醒、评分、心率；验证分期与总时长相符。
- 兴趣收藏：番剧、游戏、Galgame、书籍、电影；进度、评分、路线、角色、感想、封面、收藏状态。
- 后日谈：日常复盘与记录汇总；角色互动包含一/二周目、好感、结局和成就。
- 外观：私宅/简约、预设和自定义背景、透明度、场景、动效、问候语音。语音由主动操作触发。
- JSON 导出/恢复保持 V8 的个人记录格式。全站备份另见部署文档，包含读者、审核、相册等完整数据库。

## GitHub / Gitee 动态

个人设置选择平台并填写用户名即可；不是 OAuth 登录，也不需要把仓库私钥交给网站。GitHub 仓库托管与个人动态平台的选择互不影响。

显示的是平台公开事件，不是完整年度贡献或全部提交。每次同步读取最近最多 100 条事件，按 UTC 展示在 365 天日历上。没有返回事件的日期不代表没有编程活动。

- 页面立即返回 SQLite 中的上次结果，后台请求平台。
- 正常刷新间隔 30 分钟；后台总超时 6 秒。
- 相同账号的并发请求合并，数据库租约防止重复同步，重启保留缓存。
- 使用 ETag，平台返回 304 时保留数据；错误时保留旧结果，15 分钟后重试。
- 403/429 时至少退避 1 小时，并遵守平台 Retry-After / 额度重置时间。
- 前端合并请求和短时缓存。刷新按钮读取缓存，不绕过平台冷却时间。
- 可选 `GITHUB_TOKEN` 仅留在服务器环境中；不会下发浏览器，Gitee 请求不携带它。

## 机器人接口

在私人设置创建令牌，通过 `Authorization: Bearer space_…` 调用 `POST /api/ingest`。只允许健康、餐食、睡眠数据；令牌不能读取私人空间或发布文章。令牌有效期 90 天，可随时撤销。

```json
{"kind":"health","key":"device-2026-10-26","source":"my-device","data":{"date":"2026-10-26","steps":8000}}
```

同一个令牌和 `key` 的相同请求返回原记录，内容不同返回 409。不要把令牌放进 URL、前端代码或 Git 仓库。
