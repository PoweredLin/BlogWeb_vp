## 本轮需求落地

| 需求 | 当前实现与入口 |
| --- | --- |
| 更多页面自定义 | 管理 → 页面布局：公开首页和私人空间模块显隐、排序；空间外观与博客设置负责背景、主题、头像与首页表现 |
| 文章自选封面预览 | 本地图片即时预览，上传状态、失败提示和重试；草稿图片保持私有，公开文章关联后才公开 |
| 品牌和电影片头 | 默认站名“拾帧之间”，设置可更换；照片拼字后淡出衔接轮播，支持跳过、低动效与超时退出 |
| 个人空间和管理分工 | 共用同一外壳与登录态；空间承载兴趣、日常、创作，管理分区承载审核、配置和自动化 |
| 本地与云端分工 | 云端固定模板、调度、结果收件箱、人工确认和邮件；本地 AI/浏览器承担较重的检索与整理，经受限接口提交结果 |
| 邮件推送 | SMTP 配置、测试、手动发送、周报范围、时间/时区、自动计划、发送历史和明确失败重试；未知投递状态避免重复发送 |
| AI Access Token | scope、到期、撤销、摘要存储、发布权限分离、幂等；文章草稿、显式授权发布、JSON 校验及导入 |
| 轻量任务流 | 新番、空间周报、本地资料三种模板，可编辑计划与输出；持久队列、取消、去重、恢复和人工确认 |
| 季度新番 | 固定 Yuciwiki 来源、限量抓取、封面检查、私人预览，确认后保存收藏、私有文档或邮件 |
| 开发文档 | 白名单开发书架内嵌及原站回退；站主 Markdown 笔记和 Mermaid 流程图 |
| Git 动态性能 | 持久缓存、后台刷新、并发合并、ETag、限流退避；不在每次访问时等待平台请求 |
| 权限隔离 | 访客仅公开内容；读者仅自己资料和待审核评论；站主管理内容与私人空间，注册与评论均需审核 |

可编辑性围绕页面与模板参数实现；业务功能仍随版本发布。不引入通用低代码平台、任意代码插件运行器或跨平台客户端。

## 季度海报墙、管理拆分和素材补充

本轮新增公开 `/anime` 与私有 `/admin/anime-wall` 的季度管理；采集结果先人工确认，确认后的番剧受“自动公开”总开关控制，手动收藏可单独公开。管理和功能已拆成 `/admin/management`、`/admin/features`。片头上传 URL 已修复，精选图片支持预览、排序与移除。

素材路径、接口、SQLite 适用范围及 Claude 提示词见 [季度海报墙与素材交接](季度海报墙与素材交接.md)。当前单实例个人站继续使用 SQLite，无需迁移数据库；保留备份与上传文件。

## 前端交给 Claude

使用 [Claude 前端设计交接](Claude前端设计交接.md) 内的首页及私宅提示词。保留 Vue 组件输入/事件、统一 service、路由、API 字段及权限；主要调整视觉、布局、动效、响应式与状态反馈。简约主题和私宅主题应有明确差别，不另建一套重复后台。

完整功能与 AI 请求示例见 [功能说明](FEATURES.md)。本地执行器示例为 `scripts/local-ai-submit.py`，仅通过环境变量读取 Access Token。

## 验证与升级边界

本轮后端回归为 29 项 Python、17 项 Node 测试；另有完整浏览器、多宽度外观和封面预览专项。验收结论与限制见 [安全记录](SECURITY.md)。

演示不代表已更新线上服务器。发布代码通过 GitHub main 交付；本轮未切换反向代理或操作生产库。真实 SMTP 投递需你配置稳定密钥和服务商授权码后验收；Docker 构建及容器运行需在有 Docker Engine 的环境验证。第三方文档是否可内嵌、新番来源的即时可达性，以来源站策略和服务器网络为准，失败时界面应保留错误和重试入口。

生产升级统一按 [V9 → V10 升级与回滚](V10-upgrade-and-rollback.md)，先用线上数据副本预演，再停写备份、迁移、验收和切换。保留旧镜像、配置和完整数据快照；不要执行 `docker compose down -v`。
# 季度番剧与首页模块

在个人空间的自动化中选择“季度新番收藏”，季度支持自动或选择 2024 年 7 月以来的季度。新建任务默认读取全部（安全上限 200 条）；已有任务保留原来的设置，可编辑为 0 读取全部。运行后需人工确认，结果才加入兴趣收藏。页面布局中的总开关控制是否公开已确认采集的新番，不会公开收藏笔记或进度。封面下载受来源可用性和单次处理时间限制，结果页会提示失败或超时。

已确认采集的番剧受“页面与片头 → 自动公开”总开关控制；手动私人收藏需要单独公开。按星期筛选从来源的播出文字识别星期，来源未标明的归入待定；这不是播放服务，也不会推断每集的实际更新时间。历史季度需要逐季运行，已有收藏去重，不会自动覆盖手动修改。

“管理 → 页面与片头”可设置首页番剧数量和季度，选择已公开书签，调整片头文字、播放频率及精选图片。书签默认私有，先在开发书架明确公开。文档是否可内嵌由外站策略决定，提供新窗口链接。保存后刷新首页。片头需要开启片头和动效；精选图片保存后会公开用于片头。
